# ПС-5 Авторизация (fw-authd)

- **Язык:** Python 3
- **Пользователь ОС:** fw-auth
- **Требования:** FR-30 – FR-37
- **Команда:** Волнухина, Карцев (вместе с ПС-6: Митяев, Цыбукова)
- **Сокет:** `/run/fw/authd.sock` (0600)

## Модули

| Модуль | Назначение |
|---|---|
| accounts | учётные записи, accounts.json, PBKDF2-HMAC-SHA-256 |
| auth | аутентификация, блокировка после 5 неудач на 60 с |
| sessions | сеансы, таймаут 15 мин, понижение прав второго RW-сеанса |
| roles | роли rw / ro, проверка права на команду |

## Принимает

| Команда | Назначение | Источник |
|---|---|---|
| `auth.login / auth.logout` | вход, выход | ПС-3, ПС-4 |
| `auth.ping / auth.check` | активность, проверка прав | ПС-3, ПС-4 |
| `user.list / add / edit / delete` | учётные записи | ПС-3, ПС-4 |
| `session.list / session.kill` | сеансы | ПС-3, ПС-4 |

## Отправляет

- log.write.event → ПС-2 (E01–E07, E32, E50)
- integrity.update_baseline → ПС-6

## Правила

- Шапка каждого файла по шаблону (см. `CONTRIBUTING.md`).
- Данные от администратора и из сети проверяются на входе; данным другой подсистемы без проверки не доверяют.
- Ошибки возвращаются кодом и сообщением из `common/messages.json`; необработанные исключения не завершают процесс.
- Каждый модуль имеет unit-тесты; ПМИ своей подсистемы пишет её команда (`docs/pmi_template.md`).

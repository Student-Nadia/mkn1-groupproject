# Правила работы

- Ветки: `main` — всегда собирается; работа в ветках `<подсистема>/<кратко>` (например `filter/conntrack`), слияние через PR с ревью.
- Интерфейсы и форматы (`common/`) после 25 октября меняются только через тимлида.
- Функциональная заморозка 16 ноября: дальше только исправления дефектов.
- Данные от администратора и из сети проверяются на входе подсистемы; необработанные исключения не завершают процесс.
- Каждый модуль имеет unit-тесты.

## Шапка файла

```
/**
 * Система:     ПО межсетевого экрана (ПО МЭ)
 * Подсистема:  <имя, например ПС-1 Фильтрация>
 * Модуль:      <имя, например parser>
 * Назначение:  <краткое описание>
 * Методы:
 *   - <имя метода> — <назначение>
 */
```

(В Python — то же в docstring в начале файла.)

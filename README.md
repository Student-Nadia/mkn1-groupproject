# mkn1-groupproject

Курсовое проектирование по дисциплине «Защита информации» группы 5130201/30101 СПбПУ.
Тема: **разработка программного обеспечения межсетевого экрана** (прозрачный режим L2, Debian 12).

Спецификация — `report/report.tex`. Срок сдачи — **30 ноября 2026**.

## Структура

| Каталог | Содержимое |
|---|---|
| `common/` | протокол, типы, коды событий и сообщений, правила валидации |
| `filter/` | ПС-1 Фильтрация (C) |
| `logd/` | ПС-2 Регистрация (Python) |
| `cli/` | ПС-3 CLI (Python) |
| `web/` | ПС-4 WEB (PHP) |
| `authd/` | ПС-5 Авторизация (Python) |
| `integrityd/` | ПС-6 Целостность (Python) |
| `etc/` | конфигурация по умолчанию, службы systemd, sudoers, nginx |
| `tests/` | unit-, общие и стендовые тесты |
| `docs/` | архитектура, план, шаблон ПМИ |
| `report/` | спецификация и итоговый отчёт |

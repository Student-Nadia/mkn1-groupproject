# tests/

- `unit/<подсистема>/` — модульные тесты; запуск: `make test` (из корня).
- `shared/` — общие сценарии для CLI и web: один сценарий — один JSON с командами и ожидаемыми результатами (M-коды, поля); результаты в обоих интерфейсах должны совпадать.
- `stand/` — скрипты стенда (генерация трафика, iperf3).

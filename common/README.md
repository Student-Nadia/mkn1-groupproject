# common/

Общие определения для всех подсистем. Менять только через тимлида — после заморозки интерфейсов (25 окт) затрагивает всех.

| Файл | Содержимое |
|---|---|
| `types.h`, `rule.h`, `packet_record.h` | C-типы, структура правила, запись журнала пакетов (55 байт) |
| `events.json` | Коды событий E01..E50 |
| `messages.json` | Коды сообщений M01..M16 |
| `validation.json` | Единые правила проверки данных (CLI и web реализуют по нему) |
| `PROTOCOL.md` | Конверт сообщений, тайм-ауты, повторы |
| `fwcommon/` | Python: `protocol.py` (клиент, сервер), `codes.py` (загрузка кодов) |

# ПС-1 Фильтрация (fw-filter)

- **Язык:** C (C11)
- **Пользователь ОС:** fw-filter (+CAP_NET_RAW)
- **Требования:** FR-01, FR-05 – FR-23
- **Команда:** Егоров, Ерошкин, Чиботарь, Шишмаков, Янковский
- **Сокет:** `/run/fw/filter.sock` (0600)

## Модули

| Модуль | Назначение |
|---|---|
| io | приём и отправка кадров (AF_PACKET, TPACKET_V3) |
| parser | разбор Ethernet, IPv4, TCP, UDP, ICMP, ARP; проверка заголовков (FR-12) |
| rules | движок правил: порядок, accept / goto / drop, правило 0, rule.replace |
| conntrack | таблица состояний: TCP, UDP, ICMP Echo, таймауты |
| pktlog_client | передача записей пакетов в ПС-2 (двоичный формат 55 байт) |

## Принимает

| Команда | Назначение | Источник |
|---|---|---|
| `rule.replace` | атомарно заменить таблицу правил | ПС-3 |
| `rule.get` | вернуть таблицу правил со счётчиками | ПС-3 |
| `state.enable / state.disable` | включить / отключить контроль состояний | ПС-3 |
| `state.list / state.status` | таблица состояний / настройки механизма | ПС-3 |
| `state.delete / state.delete_all` | удалить запись / все записи | ПС-3 |
| `stats.get` | счётчики пакетов и ошибок | ПС-3 |
| `traffic.block / traffic.unblock` | заблокировать / разблокировать транзитный трафик | ПС-6 |
| `state.clear` | очистить таблицу состояний | ПС-6 |

## Отправляет

- log.write.packet → ПС-2 (двоичный формат)
- log.write.event → ПС-2 (E14, E15)

## Правила

- Шапка каждого файла по шаблону (см. `CONTRIBUTING.md`).
- Данные от администратора и из сети проверяются на входе; данным другой подсистемы без проверки не доверяют.
- Ошибки возвращаются кодом и сообщением из `common/messages.json`; необработанные исключения не завершают процесс.
- Каждый модуль имеет unit-тесты; ПМИ своей подсистемы пишет её команда (`docs/pmi_template.md`).

# ПС-2 Регистрация (fw-logd)

- **Язык:** Python 3
- **Пользователь ОС:** fw-logd
- **Требования:** FR-24 – FR-29, FR-39, FR-40
- **Команда:** Гордиенко, Уэссу, Черепанова
- **Сокет:** `/run/fw/logd.sock` (0600)

## Модули

| Модуль | Назначение |
|---|---|
| event_log | журнал событий (SQLite, схема events) |
| packet_log | журнал пакетов: двоичный кольцевой файл, буфер, блоки по 4096 записей |
| query | выборки по FR-39, постраничный вывод |
| rotation | ограничение размера: E36 (пакеты), E37 (события); очистка (E34) |

## Принимает

| Команда | Назначение | Источник |
|---|---|---|
| `log.write.event` | записать событие | все ПС |
| `log.write.packet` | записать пакет (двоичный) | ПС-1 |
| `log.query.events` | выборка событий | ПС-3, ПС-4 |
| `log.query.packets` | выборка пакетов | ПС-3, ПС-4 |
| `log.packets.clear` | очистить журнал пакетов | ПС-3, ПС-4 |
| `log.flush` | сбросить буфер пакетов на диск | ПС-3, ПС-6 |

## Отправляет

- log.write.event → self (E36, E37)

## Правила

- Шапка каждого файла по шаблону (см. `CONTRIBUTING.md`).
- Данные от администратора и из сети проверяются на входе; данным другой подсистемы без проверки не доверяют.
- Ошибки возвращаются кодом и сообщением из `common/messages.json`; необработанные исключения не завершают процесс.
- Каждый модуль имеет unit-тесты; ПМИ своей подсистемы пишет её команда (`docs/pmi_template.md`).

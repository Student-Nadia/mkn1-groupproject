# Структура проекта

Прозрачный МЭ (L2) на Debian 12: шесть подсистем-процессов, обмен JSON по Unix-сокетам (`common/PROTOCOL.md`).

| ПС | Каталог | Язык | Требования |
|---|---|---|---|
| ПС-1 Фильтрация | `filter/` | C11 | FR-01, FR-05–FR-23 |
| ПС-2 Регистрация | `logd/` | Python | FR-24–FR-29, FR-39, FR-40 |
| ПС-3 CLI | `cli/` | Python | FR-02, FR-30–FR-38, FR-44 |
| ПС-4 WEB | `web/` | PHP | FR-03, FR-30–FR-38, FR-44 |
| ПС-5 Авторизация | `authd/` | Python | FR-30–FR-37 |
| ПС-6 Целостность | `integrityd/` | Python | FR-45–FR-50 |

Системные функции (интерфейсы, маршруты, время, питание) выполняет ОС через sudo по фиксированному списку команд — отдельной подсистемы нет.

Порядок готовности: `common/` → заглушки API → ПС-5 и ПС-1 → ПС-3/ПС-4 → ПС-6 → сквозные испытания.
